# Ottfilmes

Projeto para avaliar a conversão de um catálogo de filmes em uma playlist M3U compatível com aplicativos IPTV.

## Objetivo

Gerar uma playlist M3U somente a partir de URLs de mídia diretas e autorizadas. Páginas HTML, players incorporados ou endpoints protegidos não são fontes M3U reproduzíveis por si só.

## Status

Repositório inicializado. A implementação depende da confirmação de uma API de catálogo e de URLs de reprodução diretas e autorizadas.
